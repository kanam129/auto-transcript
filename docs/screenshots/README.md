# Screenshots

Three images, referenced from the project README:

| File | What it should show |
|---|---|
| `live.png` | The live view mid-meeting: dimmed history above the reading line, the current sentence in white below it |
| `history.png` | The history list, ideally with something typed in the search box |
| `onboarding.png` | The first-run screen with the quality levels |

## Capturing them

On macOS, capture the window rather than a screen region:

1. Press **⌘⇧4**, then **Space** — the cursor becomes a camera.
2. Hold **Option** and click the window.

Holding Option omits the drop shadow, which gives a clean edge and a much smaller file. On
a Retina display the result is roughly 1440 px wide, which is the right size here.

## Before committing one

**Look at what is in the transcript.** These images go into a public repository and cannot
meaningfully be taken back. Record a public video — a conference talk, a podcast — rather
than an actual meeting with actual colleagues in it.

Check the window title bar and the device names in the top bar too, not just the transcript
text.
